## Map Upgrade Updated

Have you ever thought it was just a little too nice of the taxman to hand you such a powerful and convenient map right from the start?\
Well, fear no more.\
This mod disables the map by default (configurable), requiring a new upgrade to unlock it. Subsequent upgrades significantly increase the map’s range.

It also adds the ability to zoom the minimap using the scroll wheel for extra quality of life improvements.

The mod is highly configurable, allowing you to tailor the experience and enjoy the game with less frustration.

Please note that this mod requires **ALL PLAYERS** to have it installed.
